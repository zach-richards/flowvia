## 📌 Overview

**Flowvia** is a desktop tray tool designed to show the focus of a user and give executable suggestions on how to improve it.

The goal is to make it easier to:

- **Visualize focus in a minimalist icon**
    
- **Get data on focus improvement**
    
- **Improve focus easily with automation**
    
- **User in loop always**
    

This project is currently under active development. Things may change, break, or disappear as the project evolves.

## 🚀 Getting Started
### Installation

Clone the repository:

```bash
git clone https://github.com/zach-richards/flowvia.git
cd flowvia
```

### Running

```bash
make build
cd dist
./Flowvia*
```
